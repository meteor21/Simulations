# Source seed, not a scraped sentiment dataset

63 source profiles: 12 national, 50 state-focused, 1 metro. All 50 state-focused
sources come from the same public network/partner directory. This is a useful
starting address book, NOT evidence of ideological balance, independent ownership,
complete district coverage, accessible text or historical availability.

Profile classifications are dated October 6, 2026. In strict mode they do not
silently label earlier publications. Retrospective mode can use current geography
with an explicit historical-scope-unverified flag. Add sourced historical profile
intervals and independent legacy local papers/radio/TV to improve the panel.

The six political ratings are attributed to AllSides, observed October 6, 2026.
They are a provider's judgments, not facts established by our model. Unrated is
Unknown, never Center. Michigan Advance's listed confidence is low/initial.
No numeric provider ratings were invented. -2,-1,0,+1,+2 are OUR ordinal display
codes only; do not treat them as distances or compare to native provider scales.
